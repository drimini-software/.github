# Drimini

**Focused software made with momentum and care.**

Drimini is an AI-native software company designing and building custom
software, technical systems, and purposeful websites. AI is part of the daily
work loop; people remain accountable for product choices, engineering quality,
security, and release decisions.

## Work in public

- [drimini.com](https://drimini.com) — our live website and project-enquiry
  system, with its [source available for inspection](https://github.com/drimini-software/drimini-website).
- [Release Evidence](https://github.com/drimini-software/release-evidence) — an
  experimental local-first workbench for reviewing repository evidence and
  human decisions behind a software release or handover. Independent validation
  is still pending.

## How we work

- **Frame:** turn an ambiguous initiative into a defensible decision and an
  executable next step.
- **Build:** ship a thin end-to-end slice, learn from use, and expand toward the
  intended outcome.
- **Harden:** close the production gaps justified by the real risk and leave the
  result operable.

Agents accelerate the work. People own the outcome.
